1. FITLOG



2. FITLOG is a fitness and workout planning web application where users can explore different workouts, view workout details, create a daily workout plan, save workouts for later, and mark completed workouts.

3. Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Toastify

## Key Features

1. Workout Library
   Users can browse different workouts with details such as muscle groups, equipment, duration, calories, and rating.

2. Workout Details 
   Users can view complete workout information including description, difficulty, sets, reps, and instructions.

3. My Plan 
   Users can add workouts to their daily plan and manage their selected workouts.

4. Save for Later
   Users can save workouts and access them later from the Saved section.

5. Mark as Done & Remove
   Users can mark workouts as completed or remove them from their plan, with toast notifications for actions.
